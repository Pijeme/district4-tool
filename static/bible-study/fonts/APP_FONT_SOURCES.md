# App typography

Bundled on 9 November 2026 for offline use. Original font files are unmodified.

- Lora regular/italic variable fonts: https://github.com/google/fonts/tree/main/ofl/lora
- Space Grotesk variable font: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Rye heading font: https://github.com/google/fonts/tree/main/ofl/rye
- Bitter variable tab font: https://github.com/google/fonts/tree/main/ofl/bitter

The respective SIL Open Font License texts are included as `Lora-OFL.txt` and
`SpaceGrotesk-OFL.txt`, `Rye-OFL.txt` and `Bitter-OFL.txt`. Existing Noto Sans and Kalam files/licenses are retained
for reader/PDF compatibility. Scripture and study text use Lora; interface
controls use Space Grotesk. The applied wood/illustration theme uses Rye for
decorative headings and Bitter for the compact tab labels. Stored personal
sermon formatting is preserved.
